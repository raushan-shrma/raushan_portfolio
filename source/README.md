# Raushan Kumar — Portfolio

A responsive React, TypeScript, Vite, and Tailwind CSS portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production build uses the `/raushan_portfolio/` base path for GitHub Pages.
Vite's development server uses `/` so local links work normally.

Profile details and project links can be updated in `src/data/portfolio.ts`.
